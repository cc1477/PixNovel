功能

  • 热度排序：非会员也能用 —— 热门预览 + users入り 标签 + 多页扫描，本地按收藏数 / 收藏率 / 日均收藏 / 综合热度排序
  • 会员自动使用官方 popular_desc，并支持二次排序
  • 日榜 / 周榜 / 男女性向 / 新人榜，支持历史日期与榜单重排
  • 系列目录、上一话 / 下一话、阅读进度自动保存
  • 多种阅读主题、字体、字号、行距，连续滚动或按原文分页
  • 收藏、关注、标签屏蔽、R-18 开关、图片反代

安装说明

1. 先安装 全能签 或 LCSign，并导入你自己的证书。
2. 用 Safari 打开本页，点击对应的安装按钮，在弹窗中选择「打开」。
3. 在签名工具中完成签名后安装。

请在 iPhone / iPad 的 Safari 中打开本页，唤起签名工具需要在设备上操作。
